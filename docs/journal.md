# Troubleshooting journal

One entry per real problem. These become talk anecdotes and interview stories
("tell me about a time you debugged…"). Keep them honest and short.

## Template

### YYYY-MM-DD — <one-line symptom>
- **Where:** (local / PR pipeline / apply pipeline / GCP console)
- **Symptom:** exact error message (shortened, no secrets)
- **What I checked:** 1… 2… 3…
- **Root cause:**
- **Fix:** (commit / PR)
- **Lesson / pattern:** what I would tell another engineer
- **Talk-worthy?** yes / no
